Overview

This project provides a methodical framework to create the CITYLID dataset, which uses an openly available citywide aerial Lidar dataset, categorizes it with standard urban classes such as buildings, trees, and ground, and fuses with it detailed street features information such as driveways, medians, bikepaths, walkways, and on-street parking.

Key Features

  • Real-time spatial data processing with GIS integration
  • Language-guided robotics behaviors using LLMs
  • Sensor fusion and environmental awareness
  • Modular architecture for extensibility

Technologies Used

Python, ROS, OpenCV, GPT-based LLM APIs, QGIS, Jetson Nano, custom PCB sensors.

My Role

I designed the system architecture, implemented core control logic, and handled LLM-in-the-loop integration with edge hardware.

Outcome

This prototype successfully demonstrated dynamic language-driven task execution in semi-structured indoor settings.
